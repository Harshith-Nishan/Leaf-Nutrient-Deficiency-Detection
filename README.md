# Leaf-Nutrient-Deficiency-Detection

A deep learning-based application for detecting possible nutrient deficiencies in leaf images using MobileNetV3-Small, PyTorch, and Streamlit.

Classes
-K — Potassium Deficiency
-N — Nitrogen Deficiency
-P — Phosphorus Deficiency
FN — Healthy / Fully Nutritional

How It Works
Leaf Image
    ↓
Image Preprocessing
    ↓
MobileNetV3-Small
    ↓
N / P / K Deficiency Classification
    ↓
Confidence Score

Technologies
Python
PyTorch
MobileNetV3-Small
Streamlit
Torchvision
Scikit-learn
